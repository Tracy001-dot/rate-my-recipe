# Rate my recipe
click here to view my project (https://rate-my-recipe-by-tracy.streamlit.app/)

Rate my recipe is a recipe recommendation project i built using python and Streamlit. The idea is to help users find good recipes based on their searches.

Instead of ranking using only average ratings, i also considered how many reviews each recipe has. I used the Bayasian average method to make the ranking more balanced and reliable.

**live demo**: (https://rate-my-recipe-by-tracy.streamlit.app/)

FEATURES
* Recipe Search : users can search for recipe by entering words such as chicken or chocolate.
* Recipe Ranking : Recipes are ranked using the Bayesian average method.
* Recipe Ranking : Users can see the average rating and number of reviews for each recipe.
* Interactive Dashboard : The application is built with Streamlit, making it easy to use.
* Processed Datasets : The app loads the processed recipe data to display recommendations.

  **TOOLS USED**
* Python : Main programming language.
* Streamlit: Used to build the web application.
* Pandas : Used to load, organize and analyse the datasets.
* NumPy : Used for numerical operations.
* Streamlit Community cloud : Used to publish the application online.
