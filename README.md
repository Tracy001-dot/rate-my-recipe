#THIS IS MY RATE MY RECIPE PYTHON PROJECT

A data science python project that develops an intelligent recipe ranking system using data from food.com.
it goes beyond simple average ratings by considering the number of user reviews and engagement levels to generate more reliable recipe rankings.

#PROJECT STRUCTURE
-notebooks:contains exploratory data analysis and experiments with ranking methods
-data: stores the food.com dataset and related files.
app.py: runs the interactive streamlit dashboard.
